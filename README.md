# Naina's Birthday Website

Open `index.html` in any modern browser. It works without a server or internet connection, except that the optional decorative font loads when a connection is available.

## What's inside
- Personalized hero, note, and gift-reveal sections for Naina
- Her three photos in the gallery (`assets/photos/`)
- A gentle built-in looping tune that starts on first tap (self-contained, no external audio files)

To share it, send this whole folder (or the ZIP). Naina can extract it and open `index.html` in Chrome, Edge, Safari, or Firefox.
